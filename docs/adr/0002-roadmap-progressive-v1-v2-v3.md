# ADR 0002 - Roadmap progressive V1 / V2 / V3

## Contexte

La complexite d'un serveur MCP integre Ollama + API + auth + auto-orchestration est elevee. Tenter de tout livrer en une seule etape augmente le risque d'echec et rend le projet difficile a auditer.

## Decision

Roadmap en 3 versions (V1, V2, V3) avec critere de validation explicite par version. Chaque version doit etre stable et fonctionnelle avant de passer a la suivante.

## Consequences positives

Possibilite d'iterer, de demonstrer chaque etape (utile portfolio), de detecter les problemes tot.

## Consequences negatives

Duree totale plus longue qu'un sprint massif. Acceptable car Peter privilegie la qualite et la maitrise.
